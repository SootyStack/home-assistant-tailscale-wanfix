# Tailscale WAN Diagnostics

An independently maintained Home Assistant app based on the official Community
Apps Tailscale app, with reviewed WAN recovery behavior and bounded, sanitized
diagnostics.

This custom app is not an official Home Assistant or Tailscale release. Read
the [full documentation](DOCS.md) and the repository
[release policy](../README.md) before installation.

The repository candidate is experimental. Do not run it at the same time as
another Tailscale app on the same Home Assistant host.
